# RedNote Writer

小红书文案写作模块。根据素材（网页/文章/话题）提炼核心亮点，输出标题、正文、Hashtag。

---

## 素材收集

收到素材后，通读理解核心信息：
- 提取主题、最重要的 3-5 个要点
- 识别适合小红书展示的核心亮点（数字、对比、榜单、反差感）
- 判断调性：硬核干货 / 轻松娱乐 / 种草推荐 / 知识科普

如果素材是网页，用 `browser_navigate` + `browser_console` 抓取：
```js
document.body.innerText
```

---

## 内容策划（核心原则）

**小红书不是产品说明书，不要列功能。**

要的是：
- **好奇**：开头就要让人停下来，「真的吗？」「我也想知道」
- **情绪**：有情绪的文章才会被转发，不是有逻辑的文章
- **参与感**：让人想评论、想参与、想说「我也是」

### 小红书标题底层逻辑

平台靠算法分发，算法看「完播率 + 互动率」，标题决定用户点不点。

爆款标题底层是**情绪触发**，不是信息量。

共性特征：
- 开头就有钩子，不要铺垫
- 不能读出「说明书味」
- 让人看完想知道更多

### 六大型（优先级排序）

| 类型 | 公式 | 例子 |
|------|------|------|
| **反差** | 「XX居然能YY」 | 用八字推MBTI，朋友说太准了 |
| **好奇** | 「试了X次，结论是...」 | 试了10个八字样本，结果全中 |
| **身份** | 「XX属性的人一定要看」 | ENTJ注意，你的八字可能是这个 |
| **数字** | 「3个特征」 | 3个MBTI里最卷的八字配置 |
| **共鸣** | 「你是不是也这样」 | 身边爱抬杠的人，基本是这个八字 |
| **行动** | 「进来测/快来试」 | 评论区留八字，我帮你推MBTI |

### 生成标题（3 个备选，每个 ≤ 20字）

从六大型中选最有张力的3种组合，标题里要带情绪词或反差词。

### 推荐 Hashtag

每个帖子 5-8 个 Hashtag：
- 1-2 个话题 tag（如 #AI #效率工具）
- 1-2 个平台 tag（如 #小红书成长日记）
- 内容相关垂直 tag
- 热门 tag 穿插

---

## 交付格式

标题、正文、Hashtag 全部在图片完成后再发送：

```
标题（每个 ≤ 20字）：
1. [标题1]
2. [标题2]
3. [标题3]

正文：
[正文内容]

推荐 Hashtag：
#XXX #YYY #ZZZ ...
```

---

## 注意事项

- 正文每段 2-4 句，禁止一行一句
- 枚举内容合并一行（顿号连接）
- 结尾不留刻意来源句
- Hashtag 不要超过 8 个
- **永远不要用说明文语气写小红书**
- **永远不要在开头解释"这是什么"**——直接丢结论或抛出问题
- **参与感收尾**：结尾要让人想评论，不想评论的结尾是失败的
