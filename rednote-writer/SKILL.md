# RedNote Writer

小红书文案写作模块。根据素材（网页/文章/话题）提炼核心亮点，输出标题、正文、Hashtag。

---

## 素材收集

收到素材后，通读理解核心信息：
- 提取主题、最重要的 3-5 个要点
- 识别适合小红书展示的核心亮点（数字、对比、榜单、反差感）
- 判断调性：硬核干货 / 轻松娱乐 / 种草推荐 / 知识科普

如果素材是网页，用 `browser_navigate` + `browser_console` 抓取：
```js
document.body.innerText
```

---

## 内容策划（核心原则）

**小红书不是产品说明书，不要列功能。**

要的是：
- **好奇**：开头就要让人停下来，「真的吗？」「我也想知道」
- **情绪**：有情绪的文章才会被转发，不是有逻辑的文章
- **参与感**：让人想评论、想参与、想说「我也是」

### 标题公式

小红书标题优先级：
1. **反差/反常识**：「XX居然能算出XX」「XX和XX原来是这个关系」
2. **好奇心**：「试了3次，结果每次都准」「这个东西没人告诉过你」
3. **共鸣**：「你是不是也这样」「身边一定有这种人」

禁忌：
- ❌ 罗列功能点（「支持3种模式、5种格式」）
- ❌ 说明文语气（「这个skill的作用是...」）
- ❌ 纯概念解释（「MBTI是一种...」）

### 生成标题（3 个备选，每个 ≤ 20字）

小红书标题公式：
- 数字法：「5 个技巧」「3 步搞定」「99% 人不知道」
- 悬念法：「为什么...」「...是什么体验」「...的正确姿势」
- 利益法：「免费」「必装」「保姆级」「手把手教你...」

优先选数字法 + 利益法组合，点击率更高。

### 推荐 Hashtag

每个帖子 5-8 个 Hashtag：
- 1-2 个话题 tag（如 #AI #效率工具）
- 1-2 个平台 tag（如 #小红书成长日记）
- 内容相关垂直 tag
- 热门 tag 穿插

---

## 交付格式

标题、正文、Hashtag 全部在图片完成后再发送：

```
标题（每个 ≤ 20字）：
1. [标题1]
2. [标题2]
3. [标题3]

正文：
[正文内容]

推荐 Hashtag：
#XXX #YYY #ZZZ ...
```

---

## 注意事项

- 正文每段 2-4 句，禁止一行一句
- 枚举内容合并一行（顿号连接）
- 结尾不留刻意来源句
- Hashtag 不要超过 8 个
- **永远不要用说明文语气写小红书**
- **永远不要在开头解释"这是什么"**——直接丢结论或抛出问题
- **参与感收尾**：结尾要让人想评论，不想评论的结尾是失败的
