# RedNote Writer

小红书文案写作模块。根据素材（网页/文章/话题）提炼核心亮点，输出标题、正文、Hashtag。

---

## 素材收集

收到素材后，通读理解核心信息：
- 提取主题、最重要的 3-5 个要点
- 识别适合小红书展示的核心亮点（数字、对比、榜单、反差感）
- 判断调性：硬核干货 / 轻松娱乐 / 种草推荐 / 知识科普

如果素材是网页，用 `browser_navigate` + `browser_console` 抓取：
```js
document.body.innerText
```

---

## 内容策划（核心原则）

**小红书不是产品说明书，不要列功能。**

要的是：
- **好奇**：开头就要让人停下来，「真的吗？」「我也想知道」
- **情绪**：有情绪的文章才会被转发，不是有逻辑的文章
- **参与感**：让人想评论、想参与、想说「我也是」

### 开头公式：画面感 + 离谱感 + 转折钩子

开头有两种高点击率结构：

**结构一：画面感（让用户自动代入）**
不用抽象词，用具体行为描述，让读者脑子里出现一个人。
- ❌ 「有没有那种ENTP」
- ✅ 「嘴停不下来 / 爱抬杠 / 脑子里永远有10个新点子」
- ✅ 「凌晨3点还在想方案 / 发消息永远最后回」

**结构二：离谱感（反直觉事件）**
直接点出这件事有多荒谬，调动「真假的？说说看」的心理。
- ✅ 「我最近干了一件挺离谱的事」
- ✅ 「把八字和MBTI放在一起研究，身边朋友都说我想多了」
- ✅ 「用八字推MBTI这件事，我是认真的」

**结构三：转折钩子（在中间拉住读者）**
平铺直叙之后，加一句「但」或「发现一个很诡异的点」，让读者继续往下看。
- ❌ 「研究了10个样本，发现有一些规律」
- ✅ 「研究了10个样本，发现一个很诡异的点」

**冲爆款专用：对抗式开头**
用「别XX了」句式，直接挑战一个流行观念，引发争议和好奇。
- ✅ 「别测MBTI了，用八字更准（评论我帮你看）」
- ✅ 「MBTI要做一堆题，但八字不用」

三种结构可以叠加：
「我最近干了一件挺离谱的事——用八字推MBTI。一开始朋友都说我在瞎搞。但看了10个人之后，发现一个很诡异的点：」

### 结尾公式：指令闭环 + 评论率拉升

**基础版：三步闭环**
```
👉 丢八字
👉 说问题
👉 我帮你推
```

**进阶版：加一句评论激励（让评论区更热闹）**
在指令之后加一句，调动读者「被选中」的心理：
- ✅ 「我会优先回前50个」
- ✅ 「我会挑典型的详细讲」
- ✅ 「评论越多，我越有动力出第二期」

**禁止：**
- ❌ 空泛收尾（「大家可以试试」「欢迎留言」）
- ❌ 说明文总结（「以上就是全部内容」）
- ❌ 留悬念（「下期再见」）

### 小红书标题底层逻辑

平台靠算法分发，算法看「完播率 + 互动率」，标题决定用户点不点。

爆款标题底层是**情绪触发**，不是信息量。

共性特征：
- 开头就有钩子，不要铺垫
- 不能读出「说明书味」
- 让人看完想知道更多

### 六大型（优先级排序）

| 类型 | 公式 | 例子 |
|------|------|------|
| **反差** | 「XX居然能YY」 | 用八字推MBTI，朋友说太准了 |
| **好奇** | 「试了X次，结论是...」 | 试了10个八字样本，结果全中 |
| **身份** | 「XX属性的人一定要看」 | ENTJ注意，你的八字可能是这个 |
| **数字** | 「3个特征」 | 3个MBTI里最卷的八字配置 |
| **共鸣** | 「你是不是也这样」 | 身边爱抬杠的人，基本是这个八字 |
| **行动** | 「进来测/快来试」 | 评论区留八字，我帮你推MBTI |

### 生成标题（3 个备选，每个 ≤ 20字）

从六大型中选最有张力的3种组合，标题里要带情绪词或反差词。

### 推荐 Hashtag

每个帖子 5-8 个 Hashtag：
- 1-2 个话题 tag（如 #AI #效率工具）
- 1-2 个平台 tag（如 #小红书成长日记）
- 内容相关垂直 tag
- 热门 tag 穿插

## 交付格式

标题、正文、Hashtag 全部在图片完成后再发送：

```
标题（每个 ≤ 20字）：
1. [标题1]
2. [标题2]
3. [标题3]

正文：
[正文内容]

推荐 Hashtag：
#XXX #YYY #ZZZ ...
```

---

## 注意事项

- 正文每段 2-4 句，禁止一行一句
- 枚举内容合并一行（顿号连接）
- 结尾不留刻意来源句
- Hashtag 不要超过 8 个
- **永远不要用说明文语气写小红书**
- **永远不要在开头解释"这是什么"**——直接丢结论或抛出问题
- **参与感收尾**：结尾要让人想评论，不想评论的结尾是失败的
